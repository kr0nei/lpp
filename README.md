# Raycast razširitev za LPP

## Namestitev
V terminal-u
```bash
git clone https://github.com/kr0nei/lpp
```

V Raycast
- Import Extension
- Choose lpp folder
## Uporaba
Napiši 'bus' v raycast, kot opcijsko lahko vpišeš tudi ime postaje za katero te zanima urnik prihodov. V primeru, da ne napišeš postaje, dobiš rezultat za vse postaje. Nato se ti prikažejo vse filtrirane postaje in njihova smer. Ko izbereš smer se ti še pokažejo linije ki so na voljo. Ko še linijo izbereš se ti pokaže urnik
